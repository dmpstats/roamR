# wrapper on slice_strs() to slice density surface with appropriate indices. Slice construction relies on `cfg` to define the available non-raster dimensions to evaluate

wrapper on slice_strs() to slice density surface with appropriate
indices. Slice construction relies on `cfg` to define the available
non-raster dimensions to evaluate

## Usage

``` r
extract_dns_layer(dns_strs, cfg, timestep)
```

## Arguments

- dns_strs:

  object containing the density datacube
